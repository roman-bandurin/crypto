Crypto — Web Crypto API Playground & Agentic Tool Server

A browser application for hands-on cryptography: pick an algorithm, generate keys, encrypt, decrypt, sign and verify — all through the native Web Crypto API. The same operations are exposed to AI agents via W3C WebMCP (navigator.modelContext) and an in-app chat that speaks the [OI] tool-calling protocol with LM Studio or any compatible endpoint.

Supported Algorithms

Hashing

DIGEST computes SHA-1, SHA-256, SHA-384 and SHA-512 hex digests of arbitrary text.

Symmetric Encryption

AES-CBC, AES-CTR and AES-GCM encrypt text with 128, 192 or 256-bit keys. The ciphertext embeds a random 128-bit initialization vector as a hex prefix.

Asymmetric Encryption

RSA-OAEP encrypts with a public key and decrypts with a private key, using SHA-1 through SHA-512 hashes and 512 to 4096-bit key sizes.

Digital Signatures

RSASSA-PKCS1-v1_5, RSA-PSS and ECDSA sign a message with a private key and verify the signature with the public key, reporting an explicit verification result.

Message Authentication

HMAC produces keyed authentication codes with SHA-1 through SHA-512 and 512 to 4096-bit keys.

AI Agent Tools

Five tools are registered for agents: list_algorithms, compute_digest, generate_keys, encrypt_or_sign and decrypt_or_verify. They run through W3C WebMCP when the browser ships navigator.modelContext, and through [OI] function calling in the in-app chat otherwise. Every handler is a pure client-side Web Crypto call: read-only, idempotent, no network access.

All keys and outputs are lowercase hex strings; asymmetric keys import as raw hex (SPKI public, PKCS#8 private). Nothing is ever sent to a server: the entire cryptographic surface executes in the browser. The optional AI chat talks only to the endpoint configured by the user.
